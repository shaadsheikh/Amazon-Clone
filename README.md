# 🛒 Amazon Clone

A frontend **Amazon Clone** built as my **first-ever web development project** while learning the fundamentals of HTML and CSS.

This project was created in **2024** as part of my learning journey through the **Apna College** web development resources by **Shradha Khapra Ma'am**. It helped me understand how real-world websites are structured and gave me hands-on experience building a multi-section e-commerce interface from scratch.

> 🚀 **My First Project | 2024 | Learning by Building**

---

## 📌 About The Project

This repository contains a simple clone of the Amazon website's user interface.

The goal of this project was **not to build a fully functional e-commerce platform**, but to practice frontend development concepts and understand how to recreate the structure and visual layout of an existing website.

As my first project, it was an important milestone in my journey of learning web development.

---

## ✨ Features

- 🏠 Amazon-inspired homepage
- 🔍 Search bar UI
- 🧭 Navigation bar
- 📦 Product/category sections
- 🛍️ Shopping cart interface
- 👤 Account/sign-in section
- 📍 Location/delivery section
- 📱 Responsive layout basics
- 🎨 Amazon-inspired styling and layout

> **Note:** This is a frontend learning project. Features such as authentication, product management, payments, and real-time cart functionality are not implemented.

---

## 🛠️ Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling and layout
- **Font Awesome** — Icons

## 🚀 How to Run

Since this is a frontend project, you don't need to install any dependencies.

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Amazon-Clone
```

### 3. Run the project

Open `index.html` in your browser.

Alternatively, you can use the **Live Server** extension in VS Code for a better development experience.
